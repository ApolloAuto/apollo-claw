```cpp
/*这段代码主要用于对障碍物进行排序，以便后续的路径规划。它会遍历障碍物列表，仅处理在路径规划范围内
且在车辆前方的障碍物。然后，将每个障碍物的感知 SL 边界拆分为两个边界，一个在 start_s 处，另一个在
end_s 处，并将它们添加到 sorted_obstacles 中。最后，根据这些边界的位置进行排序，以确保它们按照一定
顺序排列。FLAGS_obstacle_lat_buffer 在这段代码中的作用是调整障碍物的横向边界，以考虑其横向尺寸，
从而影响路径规划的安全性和效果。*/
std::vector<ObstacleEdge> PathBoundsDeciderUtil::SortObstaclesForSweepLine(
    const IndexedList<std::string, Obstacle>& indexed_obstacles,
    const SLState& init_sl_state) {
    std::vector<ObstacleEdge> sorted_obstacles;
    // Go through every obstacle and preprocess it.
    for (const auto* obstacle : indexed_obstacles.Items()) {
        // Only focus on those within-scope obstacles.
        if (!IsWithinPathDeciderScopeObstacle(*obstacle)) {
            continue;
        }
        // Only focus on obstacles that are ahead of ADC.
        if (obstacle->PerceptionSLBoundary().end_s() <
            init_sl_state.first[0]) {
            continue;
        }
        // Decompose each obstacle's rectangle into two edges: one at
        // start_s; the other at end_s.
        const auto obstacle_sl = obstacle->PerceptionSLBoundary();
        sorted_obstacles.emplace_back(
            1,
            obstacle_sl.start_s() - FLAGS_obstacle_lon_start_buffer,
            obstacle_sl.start_l() - FLAGS_obstacle_lat_buffer,
            obstacle_sl.end_l() + FLAGS_obstacle_lat_buffer,
            obstacle->Id());
        sorted_obstacles.emplace_back(
            0,
            obstacle_sl.end_s() + FLAGS_obstacle_lon_end_buffer,
            obstacle_sl.start_l() - FLAGS_obstacle_lat_buffer,
            obstacle_sl.end_l() + FLAGS_obstacle_lat_buffer,
            obstacle->Id());
    }
    // Sort.
    std::sort(sorted_obstacles.begin(), sorted_obstacles.end(),
              [](const ObstacleEdge& lhs, const ObstacleEdge& rhs) {
                  if (std::get<1>(lhs) != std::get<1>(rhs)) {
                      return std::get<1>(lhs) < std::get<1>(rhs);
                  } else {
                      return std::get<0>(lhs) > std::get<0>(rhs);
                  }
              });
    return sorted_obstacles;
}
```
> **INFO**
> 该函数被GetBoundaryFromStaticObstacles递归调用，这个递归调用的目的是在路径上的每个路径点检查是否有障碍物进入或离开了路径。在路径点之间的迭代过程中，函数会根据障碍物的位置和方向来更新路径的边界信息。

因此我们可以设置障碍物的横向缓冲距离来调整车辆遇到障碍物的绕行距离
