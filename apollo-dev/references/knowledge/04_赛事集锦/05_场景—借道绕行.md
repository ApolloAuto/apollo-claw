# Apollo EDU 场景集锦--借道绕行场景

> 作者: 宇新 | 发布时间: 2024-04-17 20:24 | 链接: https://apollo.baidu.com/community/article/1250

## 场景描述：

	车在单向车道行驶时，如遇前方车辆出现故障，主车可以借道绕行，为了保证行驶安全，借道区域应该在30米内。

## 评判标准：

车在规定时间内或者30m范围内完成绕行，超出30m本场景计0分。

# 2、借道绕行配置实践实验流程：

## 借道绕行配置参数同步

输入全局配置参数同步指令，系统将自动将全局配置参数复制到profile的default目录中，然后就可以在profile目录上轻松修改配置参数。

```bash
buildtool profile config init \
    --package planning-task-lane-borrow-path \
    --profile=default
```
使用default目录这份配置

```bash
aem profile use default
```

查看profile插件目录结构：

tree

```bash
profiles/default/modules/planning/tasks/lane_borrow_path/
```
目录结构：

```bash
profiles/default/modules/planning/tasks/lane_borrow_path/
`-- conf
    `-- default_conf.pb.txt
```

## 借道绕行配置实践：
**选择借道通行场景：**

**原始配置参数仿真：**

**修改借道（crosswalk）配置参数：**

在工作apollo_workspace工作目录找到

```bash
profiles/default/modules/planning/traffic_rules/crosswalk/conf/default_conf.pb.txt配置文件，调整绕行时候的路径优化，达到我们期望绕行的效果。
```

```protobuf
path_optimizer_config {
  l_weight: 1.0
  dl_weight: 20.0
  ddl_weight: 1000.0
  dddl_weight: 50000.0
  path_reference_l_weight: 100.0
  lateral_derivative_bound_default: 2.0
}
```

修改之后保存代码后进行仿真。
