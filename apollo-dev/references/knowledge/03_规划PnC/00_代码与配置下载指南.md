# Planning 代码与配置参数下载指南

> 适用版本：Apollo EDU（PnC 赛道）

---

## 一、下载比赛 Planning 源码

### 前提

必须先进入 Apollo 容器，所有 `buildtool` 命令均在容器内执行：

```bash
# 宿主机
aem start       # 启动容器（若已启动可跳过）
aem enter       # 进入容器
```

### 下载全量 Planning 源码（推荐）

```bash
buildtool install planning*
```

执行后，planning 相关包的可修改源码将同步到工作目录的 `modules/planning/` 下。

### 下载指定插件源码（按需）

只需要修改某个插件时，用完整包名下载：

```bash
# 示例：只下载人行道 traffic rule 插件
buildtool install planning-traffic-rules-crosswalk
```

包名可在 Apollo Planning 综述文档查询：  
https://apollo.baidu.com/docs/apollo/latest/md_collection_2planning_2README__cn.html

### 下载后编译

```bash
buildtool build -p modules/planning/
```

> **重要：** 编译完成后务必执行 `aem profile use default`，防止 profile 软链被覆盖。

---

## 二、下载配置参数到 profiles

配置参数有两种获取方式，根据场景选择：

### 方式 A：buildtool 命令自动同步（推荐首次初始化）

将 planning 包的配置自动同步到 `profiles/default/`：

```bash
buildtool profile config init --package planning --profile=default
```

执行后配置会出现在 `profiles/default/modules/planning/` 下。

> **局限：** 自己新增的插件（自定义 TrafficRule / Scenario）无法通过此命令同步，需用方式 B 手动复制。

### 方式 B：手动从容器内复制（自定义插件 / 完整配置备份）

容器内 `.aem/envroot/opt/apollo/neo/share/modules/planning` 目录存放了所有已安装 planning 模块的原始配置文件。

在容器内执行：

```bash
# 1. 确保目标目录存在
mkdir -p profiles/default/modules

# 2. 将 planning 配置复制过来
cp -r .aem/envroot/opt/apollo/neo/share/modules/planning \
      profiles/default/modules/
```

复制后，`profiles/default/modules/planning/` 下即为完整配置，可直接编辑调参。

#### 使配置生效

```bash
aem profile use default
```

验证软链是否正确：

```bash
ll profiles/current   # 应显示 current -> default
```

---

## 三、两种方式对比

| | 方式 A（buildtool 命令） | 方式 B（手动复制） |
|---|---|---|
| 适用场景 | 首次初始化、官方包配置 | 自定义插件配置、完整备份 |
| 命令复杂度 | 简单，一条命令 | 需 mkdir + cp |
| 是否包含自定义插件配置 | 否 | 是 |
| 配置来源 | buildtool profile 机制 | `.aem/envroot/opt/apollo/neo/share/modules/planning` |

---

## 四、完整开发流程参考

```
# 宿主机
aem start && aem enter

# 容器内
buildtool install planning*          # 下载源码
mkdir -p profiles/default/modules    # 确保配置目录存在
cp -r .aem/envroot/opt/apollo/neo/share/modules/planning profiles/default/modules/
                                     # 复制配置参数

# 修改代码或配置...

buildtool build -p modules/planning/ # 编译
aem profile use default              # 恢复 profile 软链

# 启动仿真验证
aem bootstrap start --plus
```
