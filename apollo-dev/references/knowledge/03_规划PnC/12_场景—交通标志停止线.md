
```protobuf
stop_distance: 1.0

enabled: true

```

```protobuf
max_valid_stop_distance: 2.0
```

**修改后：**

```protobuf
max_valid_stop_distance: 3.0
```

可以发现车辆停止在停止线后2.5m左右了，且车辆可以顺利进入路口了，但又出现了新问题

## 一、场景概述

### 场景定义

主车在行驶中检测到停止标志时，需根据交通规则执行完整停车流程。场景处理分为两个核心模块：

StopSign：交通规则判断模块
StopSignUnprotectedScenario：无保护路口场景执行模块
### 处理流程

完整处理流程包含4个阶段：

PRE_STOP → STOP → CREEP → INTERSECTION_CRUISE
### 核心参数速查表

#### 交通规则配置（StopSignConfig）

| **参数** | **作用阶段** | **实际影响** |
| --- | --- | --- |
| stop_distance | PRE_STOP阶段 | 车辆到停止线的距离 |

#### 场景配置（ScenarioStopSignUnprotectedConfig）

| **参数** | **作用阶段** | **实际影响** |
| --- | --- | --- |
| start_stop_sign_scenario_distance | 场景触发 | 进入该场景的距离 |
| max_valid_stop_distance | PRE_STOP阶段 | 有效停车范围判定 |
| stop_duration_sec | STOP阶段 | 最低停车持续时间 |
| stop_timeout_sec | STOP阶段 | 最大等待时间 |
| creep_timeout_sec | CREEP阶段 | 最大缓行时间 |

## 二、核心插件解析

### 2.1 StopSign 交通规则模块

#### 2.1.1 代码结构

```cpp
class StopSign : public TrafficRule {
 public:
    bool Init(...) override;
    Status ApplyRule(...) override;

 private:
    void MakeDecisions(...);
    StopSignConfig config_;
};
```
#### 2.1.2 关键逻辑

**触发条件判断**：

```cpp
const std::vector<PathOverlap>& stop_sign_overlaps =
    reference_line->map_path().stop_sign_overlaps();
```

**决策生成逻辑**：
```cpp
// 关键代码段：检测停止标志
const std::vector<PathOverlap>& stop_sign_overlaps =
    reference_line_info->reference_line().map_path().stop_sign_overlaps();
for (const auto& stop_sign_overlap : stop_sign_overlaps) {
    if (stop_sign_overlap.end_s <= adc_back_edge_s) continue;
    // 创建虚拟障碍物
    util::BuildStopDecision(
        virtual_obstacle_id,
        stop_sign_overlap.start_s,
        config_.stop_distance(),  // 配置参数
        StopReasonCode::STOP_REASON_STOP_SIGN,
        wait_for_obstacle_ids,
        Getname(),
        frame,
        reference_line_info);
}
```
**状态管理**：

```cpp
// 使用PlanningContext保持场景状态
auto& stop_sign_status =
    injector_->planning_context()->mutable_planning_status()->mutable_stop_sign();
```
### 2.2 StopSignUnprotectedScenario 场景插件

#### 2.2.1 阶段状态机

| **阶段** | **类名** | **行为描述** |
| --- | --- | --- |
| PRE_STOP | StopSignUnprotectedStagePreStop | 减速至停止线前 |
| STOP | StopSignUnprotectedStageStop | 完全停止并观察 |
| CREEP | StopSignUnprotectedStageCreep | 低速接近路口 |
| INTERSECTION_CRUISE | StopSignUnprotectedStageIntersectionCruise | 安全通过路口 |

#### 2.2.2 状态转换条件

PLANTUML[*] --> PRE_STOP: 检测到停止标志
PRE_STOP --> STOP: 到达停止距离
STOP --> CREEP: 完成3秒停车+环境安全
CREEP --> INTERSECTION_CRUISE: 进入路口区域
INTERSECTION_CRUISE --> [*]: 完全通过路口
