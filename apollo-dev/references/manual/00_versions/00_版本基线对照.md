# 00 版本基线对照：Apollo 11.0（本工作区） vs PNC/EDU

> 本表是「分版本」手册的核心裁决表。左侧一律 `[11.0·实测]`（出处：工作区 CLAUDE.md 2026-08 实测基线 + 本 manual 各分册蒸馏，均可在本机回源）；右侧一律 `[EDU·上游]`（出处：apollo-dev SKILL.md 与 references/knowledge/ 52 篇，未在本机验证，标注到文档级）。
> 标注示例：`[11.0·实测]` `[EDU·上游]` `[通用]` `[待核]`。

## 0. 一句话差异

本工作区 = **Apollo 11.0.0 官方 package 工作区**（无EDU 内容、无 GPU 依赖的感知模型）；EDU 版 = **application-pnc 工程**（Apollo EDU Apollo EDU PnC 赛道官方形态，aem + buildtool + profiles 配置机制）。两者插件化 Planning 2.0 机制同构 `[通用]`，差异集中在：工程形态、配置管理机制、可用模块面、仿真启动方式、数据资产。
