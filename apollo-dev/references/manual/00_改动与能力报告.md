## 2. 这个 skill 现在能做什么

skill 的使用流程变成：**先判版本 → 认准 current 参数目录 → 再按问题类型检索**。能力分四块：

### 能力 A：11.0 源码级答疑（新增，`manual/`）
- 某类在哪个文件、模块结构、channel/proto 字段、插件怎么注册
- 模块"起来了但没输出"的排障（`12_planning/15`、`16_感知/10` 是现状+排障树）
- 所有结论带 `[11.0·实测]` 标签 + 可回源行号；本机与 CLAUDE.md 的 47 处漂移已登记

### 能力 B：二次开发全流程（新增，`manual/15_二次开发手册/`）
- 11.0 上加 TrafficRule / Scenario+Stage / Task / ControlTask 的**从零到生效**步骤
- 含 `buildtool create` 7 个参数坑、六件套核对表、编译→install→验证闭环（`15/05`）

### 能力 C：EDU 版知识（原有，`knowledge/` + 新增 `pnc_赛事版/`）
- 原有高频快答、速查卡片、场景解题、FAQ 全部保留
- 新增 `pnc_赛事版/00`：51 篇逐篇标注"面向版本/命令/与 11.0 差异"，解决"EDU 版文档哪些能用到 11.0"

### 能力 D：环境体检（`manual/00_versions/02`）
- 换机器 4 步核对：判形态版本 → env 实测值表 → **profile 覆盖层/current 检测** → 6 条运行前提
- 让 skill 结论"绑定在哪台机器"可判断，不盲目照搬

## 3. 文档类指引（怎么用）

**入口永远是 `references/manual/00_readme.md`**，它含：
- 分层与版本模型表（knowledge/manual/00_versions/pnc_赛事版 四层职责）
- 版本标签规范：`[11.0·实测]`（本机回源）/ `[EDU·上游]`（知识库口径）/ `[通用]`
- "按意图找文档"表 + 48 篇完整清单

SKILL.md 的「版本判别与手册路由」表是**快捷路由**：用户问 11.0 源码事实 → `manual/00_readme` 意图表；问EDU 版操作 → knowledge/；问两版差异 → `00_versions/`；问知识归属 → `pnc_赛事版/00`。

每卷内部：`00_*` 编号为入口/总览，其余按主题递进；篇内统一八节骨架（作用→符号表→机制→注册配置→扩展点→⚠️→验证→溯源），交叉引用用相对链接。
