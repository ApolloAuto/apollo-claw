## 1. 使用规则（铁律）

1. **本层结论 = 官方文档口径，未在本机回源**：凡涉及命令/路径/类名/conf，以本机 `[11.0·实测]` 的 `manual/` 为准；本层用于**看做法、学流程、对概念**，动手前必须到 `manual/00_versions/02` 核对环境、到对应 11.0 篇目核对差异。
2. **版本差异提示**：正文写 9.0 的篇目，与 11.0 大概率有差异（示例：`36-限速traffic rule` 的 `buildtool create` 参数、`43-CANBUS` 的生成工具路径、`19-组件开发` 的 BUILD 写法）。`00_索引.md` 的「与 manual/ 互链表」标了哪些已交叉核对、哪些待核。
3. **禁止复制粘贴进 `manual/`**：`manual/` 是 11.0 源码蒸馏层，保持 `[11.0·实测]` 纯度；本层内容按主题补进 skill 时，要么放本层、要么经 11.0 源码回源验证后升级标注。
4. **检索**：先查 `00_索引.md` 关键词映射；想找 11.0 等价内容 → 用「互链表」跳到 `manual/` 对应篇目。
