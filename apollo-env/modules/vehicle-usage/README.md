## 高频快答

| 问题 | 快速回答 |
|---|---|
| 无法解锁 | 检查前备厢蓄电池 → 机械钥匙 → 叫开锁师傅 |
| 启动车辆 | 电子/机械钥匙 + 踩刹车按 engine |
| 手刹摘不掉 | 系安全带 / 斜坡推车 + 放手刹 |
| 充电 | 停好断电，快充/慢充口在车头左右 |
