# 动力学模型下载

> 作者: 宇新 | 发布时间: 2025-05-28 20:49 | 链接: https://apollo.baidu.com/community/article/1298

**下载动力学模型为可选项，可根据队伍情况调整**

**前置条件，用户需要在容器内进行下面操作**

**删除原来的动力学模型**
```bash
rm -rf ~/.apollo/resources/dynamic_models/models/
```
**重新下载依赖**
```bash
buildtool reinstall dreamview
```
**关闭所有进程**
```bash
bash kill_all.sh
```
启动dreamview
```bash
aem bootstrap start --plus
```
打开可视化界面下载动力学模型
